ContextBox 設定

告訴擴充套件怎麼找到你自己電腦上的 ContextBox server。

連線

預設是 7391。server 換 port 跑的時候才要改。

token 在哪裡拿

  1. 先把 server 跑起來（在 contextbox 資料夾裡）： node --experimental-strip-types core/server.ts 它啟動時會把 token 印在終端機上。
  2. 或者直接讀檔案： cat ~/.contextbox/token
  3. 想確認 server 有沒有開，瀏覽器打開 這個網址， 看到 {"ok":true,...} 就是活著。

重新產生過 token 的話，要回來這裡重貼一次，舊的會一直被擋在門外。 同一個位址的 / 是 server 的手填頁面，server 開著就能直接開。

這把 token 會去哪裡

token 只存在這台電腦的瀏覽器裡，只有擴充套件的背景程式讀得到它。 你正在填的那個網頁看不到 token，也碰不到你的事實庫 —— 網頁想直接連本機 server 會被擋下來。
