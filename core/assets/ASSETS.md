## `quaso_v8.glb` 的來源要補上

這個 repo 用 Apache 2.0 公開，而**素材不會自動跟著程式碼的授權走**。
這個模型是自己做的、買的、還是從哪裡下載的（CC0／CC-BY／其他），要寫清楚：

- 自己做的 → 在這裡寫一句「本專案自製」就好
- 別人的 → 要寫出作者、來源網址與授權；CC-BY 那類還要在畫面上或這份文件裡標示姓名

在補上之前，**不要假設它可以隨 repo 一起散布**。真的查不到來源，最安全的做法是
把它換成一個自己做的模型，或讓面板在缺檔時退回沒有 3D 的樣子（頁面現在已經擋得住讀不到的情況）。
